# Glamour Web — site responsivo

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra a pasta `glamour_web_site`.
3. Dê dois cliques em `index.html` para abrir no navegador.

O site usa HTML, CSS e JavaScript puros. Não precisa instalar nada.
A fonte DM Sans / Playfair Display é carregada do Google Fonts quando houver internet.

## Personalizações importantes antes de publicar
- Confira e substitua o telefone/WhatsApp no `index.html` (atualmente está como número demonstrativo).
- Confira o e-mail e os links de Instagram/LinkedIn.
- Os cards do portfólio são exemplos visuais; substitua pelos projetos reais.
- Edite cores, textos e espaçamentos em `css/style.css`.

## Estrutura
- `index.html` — conteúdo e estrutura
- `css/style.css` — identidade visual e responsividade
- `js/script.js` — menu mobile e navegação do portfólio
- `assets/` — foto usada no banner
